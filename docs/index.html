Methodology

The benchmark applies the same target, horizon and scoring rule to every provider.

01

Forecast target

Daily maximum temperature stored as tmax_c for Torrevieja at latitude 37.9780 and longitude −0.6822.

02

Fixed horizon

Only D+3 forecasts are compared, using forecast_horizon_days: 3 across providers.

03

Observed actuals

Observed daily maximum temperatures are sourced from Meteostat and stored in the public CSV layer.

04

Date matching

A forecast is evaluated only when forecast.target_date == actual.date.

05

Scoring

Absolute error is calculated for each matched row; provider MAE is the mean of those errors in °C.

Primary metric

Mean Absolute Error

MAE = (1 / n) × Σ |forecasti − actuali|

MAE is directly interpretable in degrees Celsius. A smaller value means that forecasts were closer to observations on average.

Responsible interpretation

Limitations

The ranking is an empirical local benchmark, not a universal league table of weather providers.

One-city benchmark

Results apply to Torrevieja and may not generalize to inland, mountainous or different climate zones.

One forecast horizon

The project evaluates D+3 only. Provider performance may differ at D+1, D+5 or longer horizons.

Growing sample

Early rankings can move materially as more matched forecast–actual observations accumulate.

API plan constraints

Providers can expose different forecast products, update schedules and usage limits depending on their API plans.

Scope of the conclusion

The result answers one precise question about daily maximum temperature, one location, one horizon and the available sample.
