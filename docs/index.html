Methodology

How the score is calculated

  1. Collect each provider's D+3 tmax_c forecast.
  2. Match forecast.target_date to actual.date.
  3. Calculate absolute error and aggregate provider MAE.

Interpretation

What the result means

Lower MAE means better average accuracy for this location, variable, horizon and observed sample.

This is not a universal ranking of weather providers.

Data architecture

Static and reproducible

GitHub Actions updates versioned CSV files. This dashboard reads those files directly, without Supabase or frontend secrets.
